- 完成 V2-010C：新增 `src/boardroom_os/contracts/acceptance.py`、`tests/contracts/test_acceptance_contract.py`、`tests/negative/test_acceptance_contract_fail_closed.py`，并扩展 `src/boardroom_os/contracts/project.py` 与 `src/boardroom_os/contracts/__init__.py`。
