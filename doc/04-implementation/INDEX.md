后续任务优先从 `backlog.md` 开始。`backlog.md` 顶部维护 TL;DR、当前任务入口、当前验收入口、工作包规则、子项目依赖图、进度总览和当前重点。顶层 `V2-xxx` 是里程碑，实际实施必须落到 `V2-xxxA` / `V2-xxxB` 这类工作包。
